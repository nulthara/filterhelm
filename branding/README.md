# FilterHelm Brand Kit

**Multiple instances. One control plane.**

This package contains an original, minimalist vector reconstruction of the selected FilterHelm logo concept, PNG exports, color and typography tokens, and guidelines for application design and implementation.

Start with `guidelines/BRAND_GUIDELINES.md`.

**Important:** The SVGs are newly constructed assets inspired by the concept board, not exact vector tracing. Review and approve their geometry before treating them as the final public-facing identity.
