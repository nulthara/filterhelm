## How a change happens

1. Compare your instances on Drift to see which managed entries differ.
2. Follow the row's **Fix in** link to the page that owns the entry.
3. Review the change and confirm it for one instance in its dialog.

[Read more about the safety model](/understand/safety-model/).

## What you need

- Pi-hole FTL 6.x.
- Docker or Podman, or Python 3.11 or newer to run from source.
- An `amd64` or `arm64` host for the published image.

[Read more about installation](/guides/install-options/).

## Get help

1. Ask a question or report a bug in [GitHub issues](https://github.com/nulthara/filterhelm/issues).
2. Report vulnerabilities privately using the [security reporting instructions](https://github.com/nulthara/filterhelm/blob/main/SECURITY.md).
3. Read the [contributing guide](https://github.com/nulthara/filterhelm/blob/main/CONTRIBUTING.md) before sending a change.
